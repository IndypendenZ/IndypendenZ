# CryptoDash — แดชบอร์ดคริปโตส่วนตัว

เว็บแดชบอร์ดคริปโตสำหรับใช้เอง หน้าตา/ฟีเจอร์คล้ายเว็บเทรดทั่วไป **แต่ไม่มีระบบเทรด** (คุณเทรดเองที่อื่น)

- 📊 **ดูราคาเรียลไทม์** — ตารางเหรียญ Top 50 พร้อมราคา, % เปลี่ยนแปลง (1ชม/24ชม/7วัน), ปริมาณซื้อขาย, มาร์เก็ตแคป, กราฟ sparkline
- 📈 **กราฟราคา** — คลิกเหรียญเพื่อดูกราฟ 24ชม / 7วัน / 30วัน / 90วัน
- ⭐ **รายการติดตาม** — กดดาวเก็บเหรียญที่สนใจ (บันทึกในเครื่อง)
- 🔍 **ค้นหา + จัดอันดับ** — ขึ้น/ลงมากสุดใน 24ชม
- 💱 **สลับสกุลเงิน** — USD / THB
- 🌍 **ภาพรวมตลาด** — มูลค่าตลาดรวม, BTC Dominance, ดัชนี Fear & Greed, เหรียญมาแรง (Trending)
- 📐 **RSI Scanner** — คำนวณ RSI(14) ของเหรียญ Top 25 เลือกช่วงเวลา 5นาที/1ชม/1วัน + กรอง Oversold/Overbought
- 🔔 **RSI Signal + Backtest** (หน้า `/signal.html`) — กลยุทธ์ RSI 55/45 long-only, ราคา+RSI สดผ่าน Binance WebSocket, backtest เทียบ Buy&Hold (CAGR/Sharpe/MDD) · ใช้ข้อมูล Binance ไม่ต้องมี key
- 🧪 **เปรียบเทียบ 5 กลยุทธ์** — RSI 55/45, RSI+กรองเทรนด์ EMA200, MA Cross 50/200, MACD, Donchian 20/10 + แถบสัญญาณรวมต่อเหรียญ
- 📈 **MVRV** (หน้า `/mvrv.html`) — MVRV Z-Score (+ MVRV ratio ถ้ามี) ของ BTC จาก bitcoin-data.com (ฟรี ไม่ต้องมี key) บอกว่าตลาดแพง/ถูกเกินมูลค่าจริง + กราฟย้อนหลัง
- ⛏️ **ต้นทุนการผลิต BTC** (หน้า `/cost.html`) — ประมาณต้นทุนค่าไฟในการขุด 1 BTC เป็นช่วง best–worst เทียบราคาตลาด (จาก hashrate + halving + ประสิทธิภาพเครื่องขุด · ข้อมูล blockchain.info ฟรี) + กราฟ log scale พร้อมเส้น halving · เป็นแบบจำลองประมาณการ
- 💵 **หุ้น US** (หน้า `/stocks.html`) — RSI Signal + Backtest แบบเดียวกับคริปโต แต่ใช้กับหุ้นสหรัฐสภาพคล่องสูง ~20 ตัว tier บน (AAPL, NVDA, JPM ฯลฯ) · ข้อมูลราคาปิดรายวันจาก **Yahoo Finance** (สำรอง Stooq · ฟรี ไม่ต้องมี key) หรือ **Twelve Data** ถ้าใส่ key (เสถียรกว่า กัน 429) · ใช้ราคาปรับ split/ปันผล · ปรับฐานเป็นวันเทรด 252 วัน/ปี + กรองผันผวน ≤ 60%/ปี
- 🤖 **วิเคราะห์ด้วย AI (Claude)** — สรุปข้อมูลรายเหรียญ + วิเคราะห์ภาพรวมตลาดทั้งหมด
- 💬 **แชท AI** — ถาม-ตอบเรื่องคริปโตได้ทุกอย่าง (อ้างอิงราคาปัจจุบันได้)

> การวิเคราะห์/แชทด้วย AI เป็นข้อมูลเชิงการศึกษา ไม่ใช่คำแนะนำการลงทุน

ข้อมูลราคาดึงจาก **CoinGecko** (ฟรี ไม่ต้องมี API key)
การวิเคราะห์ใช้ **Claude API** ของคุณเอง (`claude-opus-4-8`)

## วิธีติดตั้งและรัน

ต้องมี **Node.js เวอร์ชัน 18 ขึ้นไป** ([ดาวน์โหลด](https://nodejs.org/))

```bash
# 1. ติดตั้งไลบรารี
npm install

# 2. ตั้งค่า API key ของ Claude (จำเป็นเฉพาะถ้าจะใช้ฟีเจอร์ AI วิเคราะห์)
cp .env.example .env
#   แล้วเปิดไฟล์ .env ใส่ ANTHROPIC_API_KEY ของคุณ

# 3. รันเซิร์ฟเวอร์
npm start
```

เปิดเบราว์เซอร์ไปที่ **http://localhost:8080**

## 🖱️ เปิดแบบกดทีเดียว (ไม่ต้องพิมพ์คำสั่ง)

**Mac:** ดับเบิลคลิกไฟล์ **`start.command`** ในโฟลเดอร์โปรเจกต์
- ครั้งแรก Mac อาจเตือนความปลอดภัย → **คลิกขวาที่ไฟล์ → Open → Open** (ทำครั้งเดียว)
- มันจะเปิด Terminal + รันเซิร์ฟเวอร์ + เปิดเบราว์เซอร์ให้อัตโนมัติ
- **ปิดเว็บ:** ปิดหน้าต่าง Terminal นั้น (หรือกด `Ctrl + C`)

**อยากให้อยู่บน Desktop:** คลิกขวาที่ `start.command` → **Make Alias** → ลาก alias ไปวางบน Desktop → ตั้งชื่อเช่น "เปิด CryptoDash" · กดเปิดได้จากหน้า Desktop เลย

**Windows:** ดับเบิลคลิกไฟล์ **`start.bat`** (สร้าง Shortcut ไปวางบน Desktop ได้)

### โหลด .env อัตโนมัติ

โปรแกรม**อ่านไฟล์ `.env` ให้เองอัตโนมัติ**แล้ว (ในโฟลเดอร์เดียวกับ `server.js`) — แค่สร้างไฟล์
`.env` ใส่ค่า แล้วรัน `npm start` ตามปกติ ค่าจะถูกโหลดให้เลย ไม่ต้องตั้งอะไรเพิ่ม

> ถ้าใส่ key แล้วโปรแกรมยังไม่เห็น (เช่น log ไม่ขึ้นว่าพบ key) ให้เช็กว่า:
> ไฟล์ชื่อ `.env` เป๊ะ (ไม่ใช่ `.env.txt`) · อยู่ในโฟลเดอร์โปรเจกต์ · เขียนแบบ `KEY=ค่า` ไม่มีเว้นวรรค

## เจอ error "CoinGecko 429 / Rate Limit" ทำยังไง

CoinGecko แบบฟรีไม่ใส่ key มีลิมิตต่ำมาก (โดยเฉพาะหน้า RSI ที่ดึงหลายเหรียญ)
แก้ด้วยการขอ **Demo API key ฟรี** (ลิมิต 30 ครั้ง/นาที):

1. สมัคร/เข้าสู่ระบบ https://www.coingecko.com/en/developers/dashboard
2. กด **+ Add New Key** → คัดลอกค่า key
3. ใส่ในไฟล์ `.env`:
   ```
   COINGECKO_API_KEY=CG-xxxxxxxxxxxx
   ```
4. รันใหม่ (`npm start`)

> ระบบมี backoff + แคช + ใช้ข้อมูลเก่าชั่วคราวเวลาโดนลิมิตอยู่แล้ว แต่ถ้าใส่ key จะลื่นกว่ามาก

## หน้า "หุ้น US" ขึ้น error 429 / ดึงข้อมูลไม่ได้ ทำยังไง

หน้าหุ้นดึงข้อมูลฟรีจาก **Yahoo Finance / Stooq** ซึ่งจำกัดจำนวนครั้งต่อ IP
ถ้าเปิดถี่ๆ หลายรอบ อาจโดน **429 (Too Many Requests)** ชั่วคราว แก้ได้ 2 ทาง:

1. **รอ ~30-60 นาที** ให้ IP คูลดาวน์ แล้วลองใหม่ (ข้อมูลแคชไว้ 30 นาทีอยู่แล้ว)
2. **ใส่ Twelve Data key (ฟรี · แนะนำ)** จะเสถียรกว่ามาก ไม่ค่อยโดนบล็อก:
   1. สมัครที่ https://twelvedata.com/ (ฟรี ไม่ต้องผูกบัตร)
   2. คัดลอก API key → ใส่ในไฟล์ `.env`:
      ```
      TWELVEDATA_API_KEY=xxxxxxxxxxxx
      ```
   3. รันใหม่ (`npm start`)

> เมื่อใส่ Twelve Data key ระบบจะใช้ตัวนี้เป็นแหล่งหลักของหน้าหุ้น (ฟรี 800 ครั้ง/วัน, 8 ครั้ง/นาที)
> โหลดครั้งแรกจะช้าหน่อย ~2-3 นาที (หน่วงกันลิมิต) แล้วแคชไว้ 30 นาที เปิดซ้ำเร็วทันที

## ขอ Claude API key ที่ไหน

1. ไปที่ https://console.anthropic.com/
2. เมนู **API Keys** → **Create Key**
3. คัดลอกค่า (`sk-ant-...`) มาใส่ในไฟล์ `.env`

> ⚠️ **อย่าแชร์ API key หรือ commit ไฟล์ `.env` ขึ้น git** (ไฟล์ `.gitignore` กันให้แล้ว) — key อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ไม่หลุดไปหน้าเว็บ

### API ภายใน

| Endpoint | หน้าที่ |
|---|---|
| `GET /api/markets?vs=usd` | รายชื่อเหรียญ + ราคา (พร็อกซีจาก CoinGecko) |
| `GET /api/coin/:id/chart?vs=usd&days=7` | ข้อมูลกราฟราคา |
| `GET /api/global?vs=usd` | ภาพรวมตลาดรวม + Fear & Greed |
| `GET /api/trending` | เหรียญมาแรง |
| `GET /api/rsi?vs=usd&tf=1d` | สแกน RSI(14) เหรียญ Top 25 (tf: 5m/1h/1d) |
| `GET /api/signal` | RSI Signal + backtest หลายกลยุทธ์ (Binance) |
| `GET /api/mvrv` | MVRV Z-Score (+ratio) ของ BTC (bitcoin-data.com) |
| `GET /api/btc-cost` | ต้นทุนการผลิต BTC (best–worst) เทียบราคา (blockchain.info) |
| `GET /api/stock-signal` | RSI Signal + backtest หุ้น US หลายกลยุทธ์ (Yahoo Finance / Stooq) |
| `POST /api/stock-analysis` | Claude วิเคราะห์สัญญาณหุ้น US (สตรีม) |
| `GET /api/status` | เช็คว่าเปิดใช้ AI ได้ไหม |
| `POST /api/analyze` | Claude วิเคราะห์รายเหรียญ (สตรีม) |
| `POST /api/market-analysis` | Claude วิเคราะห์ภาพรวมตลาด (สตรีม) |
| `POST /api/chat` | แชทถาม-ตอบกับ Claude (สตรีม) |
