# CryptoDash — แดชบอร์ดคริปโตส่วนตัว

เว็บแดชบอร์ดคริปโตสำหรับใช้เอง หน้าตา/ฟีเจอร์คล้ายเว็บเทรดทั่วไป **แต่ไม่มีระบบเทรด** (คุณเทรดเองที่อื่น)

- 📊 **ดูราคาเรียลไทม์** — ตารางเหรียญ Top 50 พร้อมราคา, % เปลี่ยนแปลง (1ชม/24ชม/7วัน), ปริมาณซื้อขาย, มาร์เก็ตแคป, กราฟ sparkline
- 📈 **กราฟราคา** — คลิกเหรียญเพื่อดูกราฟ 24ชม / 7วัน / 30วัน / 90วัน
- ⭐ **รายการติดตาม** — กดดาวเก็บเหรียญที่สนใจ (บันทึกในเครื่อง)
- 🔍 **ค้นหา + จัดอันดับ** — ขึ้น/ลงมากสุดใน 24ชม
- 💱 **สลับสกุลเงิน** — USD / THB
- 🌍 **ภาพรวมตลาด** — มูลค่าตลาดรวม, BTC Dominance, ดัชนี Fear & Greed, เหรียญมาแรง (Trending)
- 📐 **RSI Scanner** — คำนวณ RSI(14) ของเหรียญ Top 25 เลือกช่วงเวลา 5นาที/1ชม/1วัน + กรอง Oversold/Overbought
- 🔔 **RSI Signal + Backtest** (หน้า `/signal.html`) — กลยุทธ์ RSI 55/45 long-only, ราคา+RSI สดผ่าน Binance WebSocket, backtest เทียบ Buy&Hold (CAGR/Sharpe/MDD) · ใช้ข้อมูล Binance ไม่ต้องมี key
- 🤖 **วิเคราะห์ด้วย AI (Claude)** — สรุปข้อมูลรายเหรียญ + วิเคราะห์ภาพรวมตลาดทั้งหมด
- 💬 **แชท AI** — ถาม-ตอบเรื่องคริปโตได้ทุกอย่าง (อ้างอิงราคาปัจจุบันได้)

> การวิเคราะห์/แชทด้วย AI เป็นข้อมูลเชิงการศึกษา ไม่ใช่คำแนะนำการลงทุน

ข้อมูลราคาดึงจาก **CoinGecko** (ฟรี ไม่ต้องมี API key)
การวิเคราะห์ใช้ **Claude API** ของคุณเอง (`claude-opus-4-8`)

## วิธีติดตั้งและรัน

ต้องมี **Node.js เวอร์ชัน 18 ขึ้นไป** ([ดาวน์โหลด](https://nodejs.org/))

```bash
# 1. ติดตั้งไลบรารี
npm install

# 2. ตั้งค่า API key ของ Claude (จำเป็นเฉพาะถ้าจะใช้ฟีเจอร์ AI วิเคราะห์)
cp .env.example .env
#   แล้วเปิดไฟล์ .env ใส่ ANTHROPIC_API_KEY ของคุณ

# 3. รันเซิร์ฟเวอร์
npm start
```

เปิดเบราว์เซอร์ไปที่ **http://localhost:8080**

> 💡 ดูราคา/กราฟได้ทันทีโดยไม่ต้องมี API key — ส่วน **AI วิเคราะห์** ต้องตั้งค่า `ANTHROPIC_API_KEY` ก่อน

### โหลด .env อัตโนมัติ

Node 18 ไม่อ่านไฟล์ `.env` ให้เอง มี 2 ทาง:

**ทางที่ 1** — ตั้ง env ตอนรันเลย:
```bash
ANTHROPIC_API_KEY=sk-ant-xxxx npm start
```

**ทางที่ 2 (แนะนำ)** — ใช้ Node เวอร์ชันที่มี `--env-file` (Node 20.6+):
```bash
node --env-file=.env server.js
```

## เจอ error "CoinGecko 429 / Rate Limit" ทำยังไง

CoinGecko แบบฟรีไม่ใส่ key มีลิมิตต่ำมาก (โดยเฉพาะหน้า RSI ที่ดึงหลายเหรียญ)
แก้ด้วยการขอ **Demo API key ฟรี** (ลิมิต 30 ครั้ง/นาที):

1. สมัคร/เข้าสู่ระบบ https://www.coingecko.com/en/developers/dashboard
2. กด **+ Add New Key** → คัดลอกค่า key
3. ใส่ในไฟล์ `.env`:
   ```
   COINGECKO_API_KEY=CG-xxxxxxxxxxxx
   ```
4. รันใหม่ (`npm start`)

> ระบบมี backoff + แคช + ใช้ข้อมูลเก่าชั่วคราวเวลาโดนลิมิตอยู่แล้ว แต่ถ้าใส่ key จะลื่นกว่ามาก

## ขอ Claude API key ที่ไหน

1. ไปที่ https://console.anthropic.com/
2. เมนู **API Keys** → **Create Key**
3. คัดลอกค่า (`sk-ant-...`) มาใส่ในไฟล์ `.env`

> ⚠️ **อย่าแชร์ API key หรือ commit ไฟล์ `.env` ขึ้น git** (ไฟล์ `.gitignore` กันให้แล้ว) — key อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ไม่หลุดไปหน้าเว็บ

## โครงสร้างโปรเจกต์

```
.
├── server.js          # เซิร์ฟเวอร์ Express: เสิร์ฟหน้าเว็บ + พร็อกซีราคา + เรียก Claude
├── package.json
├── .env.example       # ตัวอย่างไฟล์ตั้งค่า
└── public/
    ├── index.html     # หน้าเว็บ
    ├── styles.css     # ดีไซน์
    └── app.js         # ตรรกะฝั่งหน้าเว็บ (ตาราง/กราฟ/AI)
```

### API ภายใน

| Endpoint | หน้าที่ |
|---|---|
| `GET /api/markets?vs=usd` | รายชื่อเหรียญ + ราคา (พร็อกซีจาก CoinGecko) |
| `GET /api/coin/:id/chart?vs=usd&days=7` | ข้อมูลกราฟราคา |
| `GET /api/global?vs=usd` | ภาพรวมตลาดรวม + Fear & Greed |
| `GET /api/trending` | เหรียญมาแรง |
| `GET /api/rsi?vs=usd&tf=1d` | สแกน RSI(14) เหรียญ Top 25 (tf: 5m/1h/1d) |
| `GET /api/status` | เช็คว่าเปิดใช้ AI ได้ไหม |
| `POST /api/analyze` | Claude วิเคราะห์รายเหรียญ (สตรีม) |
| `POST /api/market-analysis` | Claude วิเคราะห์ภาพรวมตลาด (สตรีม) |
| `POST /api/chat` | แชทถาม-ตอบกับ Claude (สตรีม) |

## หมายเหตุสำคัญ

- เว็บนี้สำหรับ **ใช้ส่วนตัว** ไม่มีระบบล็อกอิน/เทรด/กระเป๋าเงิน
- การวิเคราะห์ด้วย AI เป็น **ข้อมูลเชิงการศึกษา ไม่ใช่คำแนะนำการลงทุน** — ตัดสินใจลงทุนด้วยวิจารณญาณของคุณเอง
- CoinGecko ฟรีมีลิมิตจำนวนครั้งต่อนาที เซิร์ฟเวอร์จึงแคชราคาไว้สั้นๆ เพื่อลดการเรียกซ้ำ
