● ราคา BTC vs ต้นทุนการผลิต (range) · log scale

อ่านกราฟยังไง

  • เส้นเข้ม = ราคาตลาด BTC
  • แถบสีส้ม = ช่วงต้นทุน (ขอบล่าง best case เครื่องดี+ไฟถูก, ขอบบน worst case เฉลี่ยเครือข่าย+ไฟปกติ)
  • เส้นประ = ต้นทุนกลาง
  • เส้นน้ำเงินประ = วัน Halving (block reward ÷2)
  • พื้นแดง / จุดแดง = ราคาต่ำกว่าต้นทุน best case (นักขุดขาดทุนแน่นอน)

ใช้ดูยังไง

  • ราคาใกล้/ต่ำกว่าขอบล่าง = นักขุดเริ่มขาดทุน เครื่องเก่าทยอยปิด · ในอดีตมักเป็นโซนจุดต่ำสุดของรอบ
  • ราคาสูงกว่าแถบมาก = นักขุดกำไรหนา · มักเป็นช่วงตลาดร้อน
  • หลัง Halving ต้นทุนเด้งขึ้นทันที ~2 เท่า (รางวัลลดครึ่ง) สังเกตแถบกระโดดที่เส้นน้ำเงิน
